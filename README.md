# React Sign Up Page

A simple **React Sign Up Page with Form Validation** built using React and Vite.
This project demonstrates how to validate user input fields such as **Name, Email, and Password**.

## Live Demo

https://mushrifa-hussain.github.io/React-SignUp-Page/

## Features

* User Registration Form
* Name validation (required field)
* Email validation with correct format
* Password validation (minimum length)
* Error messages for invalid inputs
* Clean and beginner-friendly UI
* Built with React and Vite

## Technologies Used

* React
* Vite
* JavaScript
* CSS

## Installation

Clone the repository

```
git clone https://github.com/mushrifa-hussain/React-SignUp-Page.git
```

Navigate to the project folder

```
cd React-SignUp-Page
```

Install dependencies

```
npm install
```

Run the development server

```
npm run dev
```

## Build for Production

```
npm run build
```

## Deploy to GitHub Pages

```
npm run deploy
```
